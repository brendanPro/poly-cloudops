## Import du workflow

Le workflow principal de l’application est fourni sous forme de fichier JSON.

Fichier :
workflows/translate-text.json

Étapes :
1. Ouvrir l’interface n8n (http://localhost:5678)
2. Cliquer sur "Import"
3. Sélectionner le fichier translate-text.json
4. Sauvegarder le workflow
5. Cliquer sur "Execute Workflow"
